# 2 - Reverse engineering

How the original works, found out from `1_original/UGH.EXE`.

| Folder | Content |
|---|---|
| `notes/` | notes in Czech: the map of the executable (`phase1-map.md`), the data formats (`phase2-data.md`), the emulator and the sound (`phase3-*.md`), the way to the remake (`phase4-modernization.md`, `rewrite-audit.md`, `core-design.md`) |
| `tools/` | Node.js helper scripts (depacker, block statistics, coverage, level renderer) |
| `ghidra-scripts/` | Ghidra headless export scripts (`tools/run-ghidra-script.ps1`) |

`ghidra-project/` and `out/` are derived from the original and never committed.

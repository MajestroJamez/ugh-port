UGH! port
=========

A faithful re-implementation of the 1994 DOS game UGH! (Play Byte / Bones Park Software Artistic).
This package contains only the port; the game itself is not included.

You need your own copy of the original UGH.EXE (SHA-256
ef93d2cd5eb558f6a7d0007e0109f2e9ee952dc125389d7a6256646087636d7c). Put it into this folder next to
UGH-port.exe, or start UGH-port.exe and pick it once - the path is remembered.
The copy this port was made from was downloaded from https://mujsoubor.cz/stare-hry/ugh;
only exactly that version works.

Controls: player 1 arrow keys (up = pedal), player 2 W / Z / A / S. F1 starts, F2 password,
F3 difficulty, F4 one player / team, F5 controls, P pause, Esc ends the game, Q quits.
The high score table is kept in %APPDATA%\ugh-port.

UGH-port.exe --original runs the original program in the built-in emulator instead (no sound).

Source: https://github.com/MajestroJamez/ugh-port
